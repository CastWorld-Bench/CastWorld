# CastWorld visual assets

The three-color globe combines a world grid with a forecasting signal. Blue, teal, and gold are shared by the repository header and project site. The canonical mark is `castworld-mark.svg`; the PNG is its raster companion.

`atlas-background.png` is an AI-generated conceptual illustration of cartographic contours and time-series curves. It is decorative artwork, not a dataset visualization, geographic measurement, or experimental result. The site places it behind the heading at reduced opacity. `readme-banner.png` is a browser-rendered composition of that background, the canonical mark, Manrope typography, and the project counts.

The scientific figures in the parent asset directory are separate from this artwork and are not modified by the visual refresh. Section icons and link badges use Lucide 0.468.0; its ISC license is in `../icons/LICENSE`. Manrope is bundled under the SIL Open Font License in `site/assets/fonts/OFL-Manrope.txt` at the repository root.
